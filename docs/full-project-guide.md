# 完整项目操作指南

更新：2026-11-20；代码基线：main a6ac819（PR #5）。本指南描述当前实现，不代表独立精度认证或硬件全部验收。

逐步执行请看 [从GitHub到实机实验操作手册](github-to-hardware-guide.md)，本页为总览。

## 源码入口
- src/filters/sixAxisEskf.ts：当前六轴 A0/A4 主算法；src/filters/angleKf.ts：旧位置角演示算法。
- src/components/、src/data/：页面、六轴导入、软件干扰、共享记录、指令日志对齐；tests/：前端回归测试。
- controls/gimbal-serial/：交互控制台、安全传输、运动脚本和离线测试。
- algorithms/matlab/：用户历史 MATLAB 模型，不是当前六轴实现。
- firmware/：固件资料状态说明。厂家完整 BGC 增稳源码尚未取得；已在本地取得厂家通信示例和 HEX，不默认转载或烧录。
- docs/：算法、变更和采集指南；samples/：原仓库演示/派生数据，不是独立真值。

## 实验流程
1. 核对接线、负载、机械范围和物理断电手段。BGC负责运动/可能的自身增稳；WT61PC使用厂家上位机采集，工作台不控制设备。
2. 先用控制程序离线模拟检查，再按独立硬件流程运行已验证的运动。不要因代码有画圆/8字/多谐波模式就认定每条轨迹均实机验收。
3. 先开始WT61PC记录，再执行运动；保留动作前后静止、动作起止事件、控制日志与原始CSV/BIN。记录实际频率和主机/设备时间差，不能假定硬件同步。
4. 打开六轴主页面，固定格式用“导入记录（自动识别）”；其他格式使用“手动映射”。六轴数据成功导入后供分析、三维和位置角页共用。失败保留已有数据。
5. 通过导入弹窗附带指令CSV或“叠加指令CSV”加载同次控制记录；设置偏移和起点姿态对齐。黄虚线是指令估算。A4跟随RMSE不是独立精度，不能以调偏移使曲线更接近来证明算法准确。
6. 展示原始记录，然后切换明确标注的软件干扰，再展开九宫格观察同算法偏差和全局均值权重。实际外部干扰需另采日志；只传播帧权重1不表示接受观测。
7. 按需导出质量报告、规范化数据、算法对比或九宫格偏差/权重。不同导出的列和含义不同，勿混用旧角度诊断与六轴诊断。

## 运行
```
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1
```
开发运行 npm run dev。离线构建包可用 start-workbench.cmd（需 Python、dist，默认4180）；只启动本机页面，不打开串口。控制依赖与测试见其独立README。MATLAB本轮未做运行验证。

## 厂家工具与硬件状态
WT61PC继续使用厂家 WitMotion 上位机。用户提供文档入口：https://wit-motion.yuque.com/wumwnr/docs/qxan95 。不转载厂商安装包；下载和适配型号以厂家为准。

BGC串口公开控制采用AA 51…55；JC串口和CAN是不同协议。曾在COM10发一次JC只读查询未收到回复，不等于驱动器无此能力。厂家CAN示例可供反馈解析研究，但不是当前完整增稳源码，示例开机有闭环/回零动作，不可直接刷入替换。USB-CAN适配器当前未提供；不在本轮尝试读取、修改固件或改线。

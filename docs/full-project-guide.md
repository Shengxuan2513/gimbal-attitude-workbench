# 完整项目入口

## 源码位置
- src/、tests/：工作台、前端六轴算法、图表和回归测试。
- controls/gimbal-serial/：云台控制、周期运动、安全停止和离线测试。
- algorithms/matlab/：历史 MATLAB 分析脚本，不是当前六轴主算法。
- firmware/：固件待补状态；目前无自主 MCU 工程。
- docs/：算法、采集、演示说明；samples/、public/：原仓库既有演示资料。

## 操作顺序
1. 使用厂家 WitMotion 上位机连接 WT61PC，确认轴向、实际回传频率、时间源并记录设置。
2. 独立运行云台控制程序前先通过离线测试、核对端口与停止保护。此次归档不连接设备、不发送运动指令。
3. 上位机开始采集，再执行已验证运动；结束后保存同次 CSV/BIN 与控制日志，保留时间源和起止事件，不能假定已硬件同步。
4. 工作台导入一次，同一记录供各页共用。软件干扰不是实测干扰，偏差不是独立真值误差。
5. 新的真实日志不入库；公开前人工检查身份信息及授权。厂家程序只引用官方入口，不转载二进制和内部代码。

## 厂家上位机
使用现有厂家工具，不重新开发传感器连接。用户提供的产品文档入口：https://wit-motion.yuque.com/wumwnr/docs/qxan95
从厂家文档获取匹配型号的工具；本次不下载、转载或验证厂商安装包。

## 从源码运行
在项目根目录执行：
```
npm ci
npm test
npm run build
npm run dev -- --host 127.0.0.1
```
控制程序安装/离线测试见 controls/gimbal-serial/README.md；MATLAB 依赖及输入见其独立说明。

## 桌面演示包
本地包额外含 dist 和 start-workbench.cmd，不含 node_modules、.git、缓存、新的真实采集日志或厂家程序。
双击启动脚本使用 Python 在 127.0.0.1:4180 显示演示页面，不会启动云台或读取串口；若端口占用先关闭原进程或手动换端口。修改源码后需重新 npm ci/build；控制端需安装 requirements.txt。

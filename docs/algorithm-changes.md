## 一、保留的核心（未改变）

- **【保留】名义状态与误差结构**：单位四元数姿态 $\bar{q}$（Hamilton 标量在前）+ 三轴陀螺零偏 $\bar{b}_g$；6 维右乘局部误差 $\delta x = [\delta\theta^T, \delta b_g^T]^T$；$F_c, G_c, Q_c$ 连续传播及真实 $\Delta t$ 离散化。
- **【保留】Huber 调权与双侧白化**：固定先验切空间 Cholesky 白化 $e_x, e_y$；非平方 Huber 权重 $w=1$（$|e|\le\mu$ 或 $e=0$）与 $w=\mu/|e|$（$|e|>\mu$）；$W_x, W_y$ 双侧协方差调权与固定先验 IRLS 求解；误差注入及 $T C_\xi T^T$ 协方差重置。
- **【保留】公平对照与验证原则**：标准一次 ESKF（A0）、迭代二次损失 ESKF（A1）、单侧/双侧 Huber（A2–A4）同输入同初始化同噪声对比；独立参考评价与故障注入矩阵。

## 二、针对六轴无磁配置的新增与修订

| 编号 | 类别 | 对应模块 | 具体变更内容 | 变更原因 |
| :--- | :--- | :--- | :--- | :--- |
| `6X-M01` | 修订 | 观测模型 | 观测向量固定为 $z = f_m^b \in \mathbb{R}^3$（$m=3$），删除磁场块 $m_m^b$ 与 $[h_m]_\times$，仅保留比力块 $[h_a]_\times$ | WT61PC 无磁力计数据，需将六轴作为主配置而非仅附注“可无磁运行” |
| `6X-M02` | 修订 | 雅可比与观测方差 | 观测协方差由 $\operatorname{diag}(R_a, R_m)$ 简化为 $R_a \in \mathbb{R}^{3\times 3}$，白化维数 $e_y \in \mathbb{R}^3$ | 与三维比力观测维度严格对齐 |
| `6X-M03` | 修订 | 初始化 | 取消磁力计航向初始化，改为「重力定 Roll/Pitch 倾斜 + 相对零方向 $\psi_0$」 | 无磁硬件无法绝对确定真北，必须明确相对航向基准 |
| `6X-M04` | 修订 | 状态枚举 | 将「无磁」定义为正常常态 `SIX_AXIS_NOMINAL`，不再将无磁误报为磁力计故障 | 避免六轴运行时全帧触发虚假故障告警 |
| `6X-N01` | 新增 | 初始化与记录 | 规定静止比力均值 $\bar{f}^b$ 范数检查与相对零方向 $\psi_0$ 记录格式 | 保证无磁初始化可复核、可追溯 |
| `6X-N02` | 新增 | 可观性与漂移 | 明确 Yaw 与垂直轴陀螺零偏在无磁静止/纯倾斜下不可观，Yaw 存在积分漂移 | 防止误将相对漂移当成真北或宣称三轴零偏全可观 |

## 三、当前实现状态（2026-11-20，main a6ac819）

历史“仅有位置角演示、六轴尚未接入”的描述已失效。当前 sixAxisEskf.ts 实现 A0/A4，旧 angleKf.ts 与 imuEkfInterface.ts 继续保留，不能混为一条链路。

- A0/A4 已提供六轴解算、对比导出和实际平均权重，界面共享导入、三维回放、软件干扰、九宫格及指令轨迹叠加均已落地。
- A1/A2/A3 是规划，不是当前可选算法。物理质量门控、自动标定、求解性能优化待办暂缓。
- 数学规格不等于代码已逐项验证：初始化使用前0.5s最多50帧比力、初始零偏0；没有自动静止检测。迭代上限不是独立失败状态，运行枚举未区分所有失败原因，最终诊断来自保存的迭代量。详见算法文档第九节。
- 早先表述“保留核心”指原 PDF 与补充审阅稿共同形成的方案，不能据此断言所有数学结构均直接来自原 PDF；页级来源及逐公式代码一致性仍需专项核验。原 PDF SHA 为历史登记值，本轮未重新校验原 PDF。

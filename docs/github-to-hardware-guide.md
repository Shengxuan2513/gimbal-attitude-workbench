# 从 GitHub 到实机采集与算法分析：逐步操作手册

版本：1.0；日期：2026-11-20；核对基线：main fcc0d6c（PR #6 已合并）。适用 Windows PowerShell、BGC 三轴云台、WT61PC 厂家上位机和当前工作台。

> 本手册包含以后由操作者执行的真实运动步骤，不会自动运行。编写时没有打开串口、发送指令或烧录。第一次照做时每完成一步核对“过关条件”，不要整页一次粘贴运行。软件停机不能代替物理断电。

## 0. 先分清三个程序

| 程序 | 做什么 | 不做什么 |
|---|---|---|
| Python 云台控制台 | 经 BGC 发出目标速度，保存指令/派生轨迹 | 不读取现有接口未提供的电机实际位置/速度 |
| 厂家 WitMotion 上位机 | 连接 WT61PC，保存原始传感器 CSV/BIN | 不是我们的滤波算法，不自动与控制日志硬件同步 |
| 浏览器工作台 | 导入离线日志，算法比较、调权、回放和导出 | 不打开串口，不控制电机，不采集传感器 |

电脑两个 USB 连接分别用于 BGC 与 WT61PC。不需要 USB-CAN 来完成本手册；但不能因此取得电机编码器反馈。不刷固件、不改接线、不试隐藏查询指令。本实验是“真实运动→真实采集→离线分析”，不是在线反馈闭环或独立精度认证。

## 1. 下载项目（首次安装）

先安装 Git、Node.js（带 npm）和 Python 3。打开 PowerShell，逐条检查：
```powershell
git --version
node --version
npm.cmd --version
python --version
```
过关条件：四条都能显示版本，不是“找不到命令”；若 python 指向应用商店而不运行，先修好 Python 安装/路径。Python 3.14 是本项目此前离线测试使用过的版本，不代表其他版本都已验证。

在桌面创建专用目录并从 GitHub 下载：
```powershell
$Base = Join-Path $env:USERPROFILE 'Desktop\云台实验'
New-Item -ItemType Directory -Force -Path $Base | Out-Null
Set-Location $Base
git clone https://github.com/Shengxuan2513/gimbal-attitude-workbench.git
Set-Location .\gimbal-attitude-workbench
$Project = (Get-Location).Path
git rev-parse HEAD
git status --short
```
目录已存在时不要反复 clone 或覆盖；先用第2节检查。保存完整提交号。下载 ZIP 也可以（仓库 Code → Download ZIP → 完整解压），但 ZIP 没有 Git 历史，不能使用 git pull/rev-parse；从 GitHub 页面另记下载分支/提交号。不要直接在压缩包内运行。

过关条件：根目录含 package.json、src、docs、controls；controls/gimbal-serial 内含 gimbal_console.py。不要用很早的桌面包冒充最新下载。

## 2. 已有副本如何更新

仅 Git 下载适用。进入自己下载的项目根目录：
```powershell
Set-Location "$env:USERPROFILE\Desktop\云台实验\gimbal-attitude-workbench"
git status --short
```
如果有输出，先备份并处理本地修改，不继续拉取、不用 reset --hard。工作区干净且不在实验运行中，再执行：
```powershell
git switch main
git pull --ff-only
git rev-parse HEAD
```
实验开始后不要更新代码。当前手册与代码若菜单明显不符，暂停并核对版本，不猜按钮。

## 3. 安装依赖：仅离线准备

在项目根目录执行：
```powershell
$Project = (Get-Location).Path
npm.cmd ci
python -m venv .venv
$Py = Join-Path $Project '.venv\Scripts\python.exe'
& $Py -m pip install -r .\controls\gimbal-serial\requirements.txt
& $Py -c "import serial; print(serial.__version__)"
```
使用显式虚拟环境路径，不需要更改 PowerShell 执行策略。npm 脚本使用 npm.cmd，避免 npm.ps1 被策略阻止。安装需要网络；运行已有 dist 页面本身不需要外网。

过关条件：安装无错误，serial 能导入。ModuleNotFoundError: serial 应安装 pyserial，不是名字为 serial 的另一个包。

## 4. 离线验收：本节不连接设备

```powershell
npm.cmd test
npm.cmd run build
& $Py -m unittest discover -s .\controls\gimbal-serial\tests -v
& $Py .\controls\gimbal-serial\gimbal_console.py --help
& $Py .\controls\gimbal-serial\test_bgc.py --help
```
每条结束可立即输入 `$LASTEXITCODE`，应为0。本手册基线前端23项、控制安全离线16项；未来新增测试可能改变数量，但不能出现失败。构建的包体积警告与失败不同，需看退出码。

再试控制台默认模拟模式：
```powershell
& $Py .\controls\gimbal-serial\gimbal_console.py
```
应显示“模拟模式/dry-run，不连接真实串口设备”。这里只输入 `q` 回车退出；不要加 --real。它可显示模拟发送/应答，不代表真机已验证。

## 5. 打开工作台（窗口A）

保持项目根目录：
```powershell
npm.cmd run preview -- --host 127.0.0.1 --port 4175
```
打开终端实际显示的地址，通常是 http://127.0.0.1:4175/ 。端口占用时可能自动换端口，不要认死地址。保持此窗口运行，另开窗口做控制。

过关条件：可看到六轴分析、三维回放、软件干扰和可展开九宫格。先加载模拟样例，验证切换与播放；此时所有结果都是模拟。若缺少指令叠加按钮，先核对是否旧版本/旧构建，停止预览后重新 build。

## 6. 建立一次实验的文件夹（窗口B）

新开 PowerShell，本窗口重新设置变量：
```powershell
Set-Location "$env:USERPROFILE\Desktop\云台实验\gimbal-attitude-workbench"
$Project = (Get-Location).Path
$Py = Join-Path $Project '.venv\Scripts\python.exe'
$Run = Join-Path $env:USERPROFILE ('Desktop\云台实验记录\' + (Get-Date -Format 'yyyyMMdd_HHmmss') + '_无外部干扰')
New-Item -ItemType Directory -Force -Path $Run | Out-Null
$Run
```
保存此目录路径。把提交号、设备型号、安装照片、厂家软件版本、串口/速率、轴向、供电、环境、是否启用BGC增稳写入实验记录。不要把 .venv 或原始实验数据提交到 GitHub。

## 7. 连接检查：只识别端口，不发指令

1. 云台电机先不加动力电；固定负载、预留运动空间、线缆不缠绕，准备可立即切断动力的物理开关。
2. 确认两个 USB 分别属于 BGC 和 WT61PC，不凭历史端口号猜测。
3. 在窗口B列端口：
```powershell
& $Py -m serial.tools.list_ports -v
```
这一步不打开运动会话。必要时在安全断电条件下插拔 USB，对照设备管理器确认身份。
4. 本机此前是 BGC=COM10、WT61PC=COM9，但换电脑/重插可能改变。下面 COM10 命令只适用于再次物理确认的 BGC 端口；COM4 曾是蓝牙口，不盲用。
5. 关闭占用 BGC 端口的串口助手/其他控制脚本。WT61PC上位机只打开自己的端口。

过关条件：明确两者身份，BGC串口空闲，物理断电手段可操作。未确认就停在这里。

## 8. 配置厂家上位机与采样检查

打开厂家 WitMotion 上位机，选择正确传感器及端口，读取实际参数。不要误用 MotorTool 给电机改设置。

- 无磁六轴；记录三轴原始加速度（含重力，g）和角速度（°/s），同时记录有效设备时间。若加录模块姿态角，只作非真值对照。
- 建议从此前已成功的串口115200、回传100Hz配置开始，但必须实测验证，不能把带宽/内部采样率当输出率。实际硬件支持范围以厂家为准；改波特率后核对重连一致。
- 保存 CSV 与配套原始 BIN（软件可用时同时保留回放文件）。先做一段10～20秒静止试录，再停止、保存、导入工作台检查。这个时长仅用于检查数据链路，不是完整噪声标定。
- 检查实际 dt 中位数约0.01s才说明约100Hz；设备时钟不能固定不变，电脑接收时间可能重复，不能按电脑时间去重。
- 设备时间冻结/逆序/重复时先停查采集配置。不要为了导入强行补时间、删重复或固定插值；手动选择主机时间也必须承认其抖动并满足单调性。
- CSV/BIN包检查不等于硬件同步认证。发现尾部不完整组，记录排除原因；大量缺包或内部对齐疑点先解决，不进入算法结论。

过关条件：一份静止试录能读出六个有效原始通道、合理时间间隔；轴向/单位已确认。不要用模拟样例替代这一关。

## 9. 通电与低速点动：从这里起是真实设备操作

只有第7、8节过关且现场条件允许，操作者才执行。本轮写手册并未执行这些命令。

1. BGC加电后按厂家说明等待约5秒校准，不晃动；如自动运动异常立即切断动力。
2. 确认云台在机械安全范围中间、无异常声响。说明书Roll约±25°、Pitch约±45°只是厂家给定边界，不当作许可行程；Yaw也受线缆限制。
3. 仅在已确认端口为COM10时，在窗口B执行一次小幅Yaw点动：
```powershell
& $Py .\controls\gimbal-serial\test_bgc.py --axis yaw --speed 0.5 --duration 0.5 --real --port COM10 --baudrate 115200 --confirm-real --confirm-port-verified
$LASTEXITCODE
```
先初始零速度、再运动、最后零速度。观察是否小幅运动并实际停下；ACK和退出码0不能代替肉眼/测量确认。没转也不要盲目加速加时长。
4. 失控、持续转动、停止无应答或异常碰撞风险：立即使用物理断电，不等待软件恢复。不连续重试已锁定会话。
5. 检查姿态仍在安全中心附近。不保证点动自动回到原起点，不能把指令积分当实际回零。

过关条件：通信、方向、小幅运动与实际停止均确认。否则不做周期实验。

## 10. 先用小幅单周期彩排，再做正式5周期

启动真实交互控制台会打开 BGC 串口，并发送初始停止；不等于只看菜单：
```powershell
& $Py .\controls\gimbal-serial\gimbal_console.py --real --port COM10 --baudrate 115200 --confirm-real --confirm-port-verified
```
出现锁定/停止失败则退出排查，不继续。端口不是COM10时先改为已核实端口。

在菜单输入 `set`，按提示顺序逐项填写（每项回车）：

| 提示 | 小幅单周期彩排值 |
|---|---|
| 点动速度 rpm | 0.5 |
| 点动时长 s | 0.5 |
| 周期时长 s | 5 |
| 循环次数 | 1 |
| 起止渐变时间 s | 1 |
| Yaw幅值 ° | 5 |
| Roll幅值 ° | 5 |
| Pitch幅值 ° | 5 |
| 周期花样 | sync |

确认菜单显示已更新且幅值/速度合理，再按第11节先开采集，回控制台输入 `run`。

**不要在设好小幅值后输入 run5/run7/circle/fig8/rand。它们会切换预设并覆盖部分参数**，不是沿用刚才全部小幅设置。第一次实验只用 set → run。

**重要停机说明**：运动执行期间主循环在运行轨迹，不保证及时读取你输入的 `s`；它不是独立急停按钮。优先准备物理断电，Ctrl+C仅是软件停止尝试。运动异常不要等键盘菜单响应。

单周期成功后，若现场仍允许，使用 set 仅把循环次数改为5，其他项确认仍为5秒、三轴±5°、sync，再做正式无外部干扰记录；总运动约25秒。这里是保守起步示例，不保证所有安装都安全；不要直接跳到最大幅值。复杂轨迹另行验收。

## 11. 每次采集的实际顺序

1. 上位机新开记录；先静止5～10秒，记录电脑开始时间。
2. 回控制台再次核对模式、幅值、周期数；输入 `run`。
3. 不加外力，观察动作与线缆，保存开始/结束事件。控制台指令位置是估算目标，云台实际姿态可能受BGC增稳影响。
4. 结束后实际确认静止，再记录5～10秒；停止上位机记录并保存整套文件。
5. 控制台显示“周期运行结束：ok=True”且日志路径存在，仍需实际确认停机。输入 q 退出，返回 PowerShell后立即看 `$LASTEXITCODE`；异常/非零需要保留日志并排查。
6. 复制刚才控制台明确打印的日志，通常在项目的 controls/gimbal-serial/云台控制台指令记录_*.csv。用时间核对，别把前面的离线模拟/彩排日志当成本次实测。
7. 原样复制厂家同次 data_0.csv、data_0.bin、data.wplay（有则保存）到第6节实验目录，建议分 sensor/、command/ 子目录。不改原文件，不混用不同实验的同名 data_0.csv。

过关条件：同一次运动的传感器文件、指令日志、参数/安装记录、退出状态和实际停机观察齐全。正式第一组不做真实外部干扰。

## 12. 一次导入到工作台

1. 浏览器切到六轴分析；如果有软件干扰先恢复“原始记录”。
2. 固定WitMotion格式：点击“导入记录（自动识别）”，在文件选择器同选本次 CSV 和配套 BIN。
3. 需要手动格式/时间源/轴向设置时，使用“手动映射”，选六轴CSV、配套BIN，可同时选本次上位机指令CSV；核对单位与物理含义后确认。不能把rpm、角加速度或模块融合角度映射为原始六轴。
4. 若没同时选指令，点击“叠加指令CSV”，选本次控制台日志。
5. 核对文件名、有效帧数、时长、实际频率、缺口/排除数；“仅CSV通过”不代表BIN同步检查完成。
6. 切到三维回放、位置角演示，核对共享记录名称。旧位置角模型不是同一六轴算法；指令叠加目前主要在六轴对比图，不保证所有页面都画同一叠加层。

过关条件：同次实测记录加载成功。姿态离谱先检查安装旋转、符号、单位和初始静止段，不先调滤波参数。

## 13. 时间对齐与正确解读

- 指令 elapsed_s 从运动程序开始计时；传感器可能提前数秒记录。根据记录事件和可识别运动起止，调整“时间偏移(s)”。定义 sensor_time = command_time + offset，例如传感器相对时间5秒才开始运动，指令从0开始，可先试 +5秒，再用多个事件核对。
- 只比较重叠区间；界面提示无重叠时先查文件是否同次、偏移符号和单位。不要外推补齐整段。
- “对齐起点姿态”默认可启用，它平移到首个重叠帧的姿态，仅用于比较，不是校准或绝对参考。对齐前后设置必须记入实验记录。
- 不通过反复调偏移/参数把曲线“调成更准”。主机/设备时钟漂移和传输延迟仍需评估，固定偏移不等于硬件同步。
- 黄色虚线=指令估算；传感器模块角度=非独立参考；A0/A4=同原始IMU上的估计。跟随RMSE是相对指令差异，不能宣称真实姿态精度提升。
- 无磁Yaw为相对值，可能漂移；电机实际编码器反馈尚未接入。

## 14. 软件干扰与算法演示

先保存一份“原始记录”结果，再切“软件干扰演示”：程序仅向输入副本 ax 添加预设 +3m/s² 短时脉冲，界面显示实际时间窗和命中帧数。不会通过USB施加真实扰动，不会改变原日志。

展开九宫格：左列普通/鲁棒姿态，注意统一坐标；中列相对同算法未注入输出的偏差，不是真值误差；右列是全局平均Wy/Wx，三行重复同一全局值，不是三个姿态轴各自权重。权重1、均值下降和仅传播帧都要结合状态解释；不保证任意干扰下鲁棒算法都优于普通算法。

拖动同步时间查看干扰前、发生时和恢复后。回“原始记录”确认恢复。真实外部干扰是另一轮经安全评估的采集，不用徒手阻挡电机或敲击运动机构来替代软件演示。

## 15. 导出、记录与复现

按需保存：规范化七列CSV、质量/元数据报告、六轴ESKF对比CSV、九宫格偏差/权重CSV。旧位置角KF诊断另属独立模型。

把结果放进同次实验目录的 analysis/，另写明：Git提交号、软件版本、传感器/控制源文件、原始或软件干扰、对齐偏移及起点开关、算法参数是否默认、文件排除/质量异常、是否实际外部干扰、操作者观察。当前导出不保证自动包含每个对齐配置，必须人工补记。保留原始文件和完整配置，后续才可重复。

当前噪声参数仍为暂用值，自动标定/A1–A3/P0物理质量门控尚未接入。第一次完成的是链路与展示验收，不是全部算法科研验证。

## 16. 常见问题：遇到即暂停对应环节

| 现象 | 先做什么 |
|---|---|
| COM10拒绝访问 | 关掉占用该端口的程序，重新确认设备身份；不要抢占/强杀后立刻运动 |
| 没有ACK、运动失败或锁定 | 停止实验、必要时切动力；保留日志，查供电接线/端口/协议，不靠加大速度试错 |
| ACK正常但没转 | ACK非机械反馈；核对校准、限位、控制模式和主控状态，不盲目加幅 |
| 实际10/25Hz而非100Hz | 查厂家回传设置、输出包数、串口速率，再短录实测dt；不改时间戳伪装100Hz |
| 片上时间不动 | 保留数据，检查是否实际输出时间包/配置；不要给冻结时钟编造采样时间 |
| 导入失败 | 原数据应保留，按错误行检查；不混用不同次BIN，不补上一帧角速度掩盖缺包 |
| 两种算法几乎重合 | 正常记录可能如此，如实展示，不改图比例或参数制造优势 |
| 网页打不开 | 确认预览进程仍在跑，使用它显示的地址；构建过旧则重新build；页面不直接双击index.html |
| 新电脑出现其他COM号 | 重新识别后修改手册命令中的端口，不能沿用旧号 |

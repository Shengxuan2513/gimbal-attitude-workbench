# 六轴原始 IMU 数据采集指南（WT61PC / 六轴配置）

更新：2026-11-20

> [!CAUTION]
> **硬件与协议核实提醒**：WT61PC 无磁力计。公开资料（WT61PC-485 说明书／规格书）仅作参考，**内部 1 kHz 采样不等于串口 1 kHz 同步输出**；本指南中任何字段、输出率与轴向在接入算法前均须以实机实测核对为准，禁止未经核实假定同一行数据严格硬件同步。

---

## 一、目标 CSV Schema 与字段约定

工作台「六轴数据准备与检查」区域提供标准模板下载，推荐表头如下：

```csv
time_s,gx_rad_s,gy_rad_s,gz_rad_s,ax_m_s2,ay_m_s2,az_m_s2
```

| 字段 | 物理含义 | 推荐单位 | 常见替代单位（导入时须显式选择） | 严禁误映射的列 |
| :--- | :--- | :--- | :--- | :--- |
| `time_s` | 单调递增时间戳 | `s` | `ms`（毫秒） | 非单调包序号 |
| `gx_rad_s` | 机体系 X 轴原始角速度 | `rad/s` | `°/s`（`deg/s`） | 关节 `rpm`、欧拉角速率 |
| `gy_rad_s` | 机体系 Y 轴原始角速度 | `rad/s` | `°/s`（`deg/s`） | 关节 `rpm`、欧拉角速率 |
| `gz_rad_s` | 机体系 Z 轴原始角速度 | `rad/s` | `°/s`（`deg/s`） | 关节 `rpm`、欧拉角速率 |
| `ax_m_s2` | 机体系 X 轴原始比力（含重力） | `m/s²` | `g`（须确认 $1g = 9.80665\,\text{m/s}^2$） | 去重力线加速度、角加速度 `°/s²` |
| `ay_m_s2` | 机体系 Y 轴原始比力（含重力） | `m/s²` | `g` | 去重力线加速度、角加速度 `°/s²` |
| `az_m_s2` | 机体系 Z 轴原始比力（含重力） | `m/s²` | `g` | 去重力线加速度、角加速度 `°/s²` |

若另有独立参考（如标定后的云台编码器／光学动捕）或设备状态字（丢包／饱和位），**必须保存在独立文件或独立列中**，禁止与六轴原始观测混用。

## 二、时间戳、采样率与同步核查

1. **区分设备采样时间与主机接收时间**：
   - 优先记录设备硬件时间戳（若协议支持）；若仅有上位机接收时间 `host_rx_time`，须在实验记录中标明「主机接收时间」，并评估串口打包与 USB 转接带来的抖动/时延。
2. **核查真实有效输出率**：
   - 统计连续帧 `Δt` 分布（`dt_min`, `dt_med`, `dt_max`）及重复帧比例，确认实际输出率（例如 50 Hz / 100 Hz / 200 Hz）与通信波特率匹配，避免将内部采样率误作串口真实输出率。
3. **饱和、丢包与非有限值**：
   - 保留原始 `NaN`、量程饱和标志与缺包时间缺口，**不要在采集脚本中用零值或线性插值悄悄填补**；导入检查器会拒绝非有限数字、重复时间与逆序时间。

---

## 三、建议采集序列与动作规范

每次采集前，将传感器固定于云台末端并记录：安装方向草图、电源/通信波特率、串口配置与室温状态（保存为配套元数据配置，不覆盖原始 CSV）。

1. **序列 A：静止基线（建议 60～120 秒）**
   - 云台完全静止水平放置，记录相对零方向（标记物理朝向）。
   - 用途：核查静止比力范数 $\|f^b\| \approx 9.81\,\text{m/s}^2$ 及 Z 轴重力符号、统计 $R_a$ 静态方差及陀螺静态零偏／噪声。
2. **序列 B：单轴往复与阶跃（Roll、Pitch、Yaw 各自独立）**
   - 在安全限位内分别绕 X（Roll）、Y（Pitch）、Z（Yaw）单独做缓慢与中等角速度往复（先用已验证的小幅范围，例如 ±15°；不要把该示例当作设备限位许可），每轴前后保留 5 秒静止。
   - 用途：核对三轴方向正负号与安装旋转矩阵，检查各轴符号是否与右手 FLU 约定一致。
3. **序列 C：多轴组合与动态比力测试**
   - 组合旋转 + 适度快速启停，并在可控范围内记录人工/外力轻敲（或后续离线注入标准异常）作为边界测试素材。
   - **安全限位**：严格遵守云台机械限位与线缆缠绕限制，避免高速撞击或超量程饱和。


## 四、当前工作流与文件保存

WT61PC 连接与采集使用厂家上位机，不由网页直接连串口。记录软件版本、输出通道、波特率、实际时间间隔和安装方向。建议保留开始/结束静止段与可识别动作事件，先采无干扰，再采可控真实干扰；不要在电机工作时徒手阻挡或敲击机构。

保存同次 CSV、原始 BIN（如可用）、厂家回放文件及控制程序的指令 CSV。标注通电状态、BGC增稳设置、运动模式和动作起止。控制日志是指令，不是实际电机编码器记录。BGC自身增稳与工作台离线滤波要分开归因。

固定中文格式可直接导入；手动映射作为备用。只导 CSV 时不声明包完整性或通道同步。设备时钟冻结、重启、丢包、USB接收抖动需单独检查；不能仅依据BIN包数证明每行各通道严格同步。100Hz设置不等于实测100Hz，每条记录独立核查。

PR #5 支持附带指令CSV或后续叠加，sensor_time = command_time + offset；起点姿态对齐仅为比较操作，不是外部标定。相对指令RMSE与相对未注入输出偏差均不等于真值误差。

软件干扰只用于可重复演示，作用于副本；与真实干扰分开保存和标记。正式展示先彩排同次双日志，避免按结果调参。P0自动标定和物理质量门控尚未实现。

BGC说明中的Roll约±25°、Pitch约±45°是厂商说明值，仍需确认固件/机械实际限制并预留裕量，Yaw还受线缆限制。不要为了标定而越限或刷换未确认固件。

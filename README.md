# 三轴云台姿态可视化实验台

基于 Vite + TypeScript + Three.js 构建的中文单页 Web 实验台，用于本地读取三轴姿态角 CSV 日志、3D 姿态回放、人工干扰注入（单帧尖峰 / 连续区间偏移）以及滤波算法对比。所有运行时资源随项目打包，不依赖后端服务、CAN 总线或网络请求。

## 1. 算法分层说明：原文方法 vs 本轮简化模型 vs 缺失输入

1. **原文方法边界**：
   - 核心流程为状态/协方差预测、观测更新、归一化残差及 Huber 降权，完整版本包含四元数姿态名义状态与 6 维姿态误差／三轴陀螺零偏协方差。
2. **本轮简化演示模型（`src/filters/angleKf.ts`，参考文档的简化实现）**：
   - **标准角度KF（简化演示）** 与 **Huber鲁棒角度KF（简化演示）**：
     - 状态向量：每轴独立 $x = [\theta, \omega]^T$（连续角度 `°` 与角速率 `°/s`，**不称为陀螺零偏**），$H = [1, 0]$，$F(dt) = \begin{bmatrix} 1 & dt \\ 0 & 1 \end{bmatrix}$（使用真实帧间 $dt$）。
     - 过程噪声：CWNA 离散化 $Q(dt) = q \begin{bmatrix} dt^3/3 & dt^2/2 \\ dt^2/2 & dt \end{bmatrix}$。
     - 创新与 Huber 降权：采用最短周期角差 $\nu = \text{wrapDiff}(y_k, \hat{\theta}_{k|k-1})$，基础创新方差 $S_0 = H P_{pred} H^T + R$，无量纲归一化残差 $e = \nu / \sqrt{S_0}$；按 $|e| \le \mu$ 时 $w = 1$、否则 $w = \mu / |e|$ 计算 Huber 权重，采用仅观测降权（$\Psi_x = I$）$R_{eff} = R / \max(w, \varepsilon)$，并用 Joseph 形式更新协方差及检查对称性与半正定性。
     - 保留原有 **角度平滑（旧演示回退）** 模式（`src/filters/demoFilters.ts`），可在界面下拉框自由切换。
   - **工程演示选值（非原文参数）**：$q = 40.0\,\text{deg}^2/\text{s}^3$、$R = 2.25\,\text{deg}^2$、$P_0 = \text{diag}(4.0, 100.0)$、$\mu = 2.0$（界面可调）、$\varepsilon = 10^{-6}$。
3. **缺失输入与已知限制**：
   - `samples/gimbal_20261118_222038_position_derived.csv`（50 帧，0～24.656s）仅含时间与由速度推算的角位置，缺少已确认的机体系陀螺仪、加速度计、磁力计与独立真值参考。
   - **完整 IMU 姿态 EKF 接口**（`src/filters/imuEkfInterface.ts`）已独立保留；在缺少真实 IMU 输入时明确标记为「不可用」，严禁将 `rpm` 或角速度微分伪造为 IMU 输入。
   - 界面统计量统一标注为「相对原日志的偏差」（非绝对真值误差）。

## 2. 数据来源、加载与坐标系约定

- **加载新数据**（「加载新数据」）：离线打包 `samples/gimbal_20261118_222038_position_derived.csv`，按实际时间戳播放，不做重新积分、补帧或固定重采样；界面注明「由速度推算的角位置，轴约定及计算方法待确认」。
- **加载示例**（「加载示例」）：内置 18 秒（901 帧，含 `±180°` 穿越）模拟序列。
- **导入 CSV**（「导入 CSV」）：支持 UTF-8（含可选 BOM）、前几行预览、列映射（无可靠角度列时返回「未映射」并**禁用确认按钮**且提示缺少哪些映射，不误选时间列或 `rpm`/速度列）、`s`/`ms` 与 `°`/`rad` 换算、单位换算与减首帧后严格递增/有限性校验，失败时保留现有数据。
- **暂用坐标系与单次符号转换**：右手系（X 向前、Y 向左、Z 向上），默认主动旋转顺序 `ZYX`（`R = Rz(yaw) · Ry(pitch) · Rx(roll)`）；轴正负方向仅在导入时乘一次，三维模型不再二次乘方向符号。

## 3. 三轴 KF 诊断查看与导出

- **单轴切换查看**：在「诊断轴」下拉框可切换 `Roll` / `Pitch` / `Yaw`，状态栏实时展示当前帧所选轴的 `obs`、`pred`、`est`、创新 `ν`、归一化残差 `e`、Huber 权重 `w`、有效方差 `R_eff`、后验协方差对角项 `P_diag` 及对称/半正定性状态（切换诊断轴不影响三维模型、曲线与播放位置）。
- **三轴完整诊断导出**（「导出三轴诊断CSV」）：
  - 导出文件包含 `#` 开头的元数据头（当前算法、参数、数据来源文件／说明、坐标系约定及干扰配置），以及 `frame_idx, time_s, axis, obs_deg, pred_deg, est_deg, nu_deg, e, w, r_eff_deg2, p_angle_deg2, p_rate_deg2_s2, cov_symmetric, cov_psd` 共 `N × 3` 行三轴完整数据（`roll` / `pitch` / `yaw` 均为各自独立递推结果）。
  - **限制**：切换至「角度平滑（旧演示回退）」模式时无 KF 协方差／创新诊断，界面明确提示并禁用导出，不会导出残留的旧 KF 结果。

## 4. 六轴数据准备与检查（WT61PC 无磁配置）

- 在顶栏可切换 **「位置角演示链路」** 与 **「六轴数据准备与检查」**，两条数据路径状态完全隔离；同时提供 **「算法文档」「变更清单」「采集指南」** 本地离线查看入口：
  - [docs/algorithm-six-axis.md](docs/algorithm-six-axis.md)：六轴无磁 ESKF + 双侧白化 Huber 主方案。
  - [docs/algorithm-changes.md](docs/algorithm-changes.md)：相对原 PDF 与九轴补充审阅稿的逐条变更清单。
  - [docs/six-axis-capture-guide.md](docs/six-axis-capture-guide.md)：今晚 WT61PC 六轴实测采集指南。
- 六轴区域支持原始 CSV 预览、7 列映射（优先片上时间，兼容 WitMotion 中文表头与 `2000-00-00 HH:mm:ss.SSS` 无效日期格式；保留电脑时间追溯且不按电脑时间去重；区分正常跨日、设备重启与时间回退）、单位与轴向显式确认、物理含义勾选、可选配套 `.bin` 包边界/校验/截断检查（排除尾部不完整组而不补齐）、规范化七列 CSV 与质量报告导出、Schema 模板下载、原始通道波形展示，以及 **六轴无磁 ESKF（A0 标准一次 ESKF 对照 vs A4 双侧白化 Huber IRLS）** 的三轴姿态对比、双侧均值权重 $W_y / W_x$ 曲线与对比 CSV 导出（`src/filters/sixAxisEskf.ts`；注：当前噪声参数 $S_g, S_{bg}, R_a$ 仍为暂用待标定值，Yaw 为相对零方向且存在积分漂移，不驱动位置角演示链路的 3D 姿态模型）。

## 现场演示页面

启动后默认显示简洁演示页：导入记录 → 播放 → 查看三维姿态与三轴对比。

- 「导入记录」直接读取 WitMotion 中文 CSV，无需逐列匹配；可同时选择同次记录的 BIN 做完整性检查。默认使用片上时间、g、°/s 和正轴向配置。异常时间不会静默改用电脑时间；请进入「数据检查」人工确认。缺少 BIN 时不声明通道同步已验证。
- 曲线显示标准 ESKF 和鲁棒 ESKF；CSV 有完整且时间对应的传感器姿态角时增加蓝色对照（非真值），Yaw 以首帧为相对零方向。模型可切换数据源，播放、进度条、曲线点击和重新播放共用时间轴。
- 「加载演示」为明确标记的模拟样例，不是真实采集。主屏不提供算法参数调整。
- 「数据检查」保留原有两个工作区、诊断、参数、文档与导出；「手动导入到演示」可使用原六轴映射弹窗，确认后更新演示页。点击「返回演示」回到简洁主屏。位置角人工干扰演示仍在原工作区，不冒充六轴真实干扰。
- 本轮仅新增展示与固定格式导入适配，未修改 `src/filters/` 内的算法、默认参数或公式。独立真值、轴向安装和噪声标定等原有限制不因 UI 简化而消失。

# MATLAB 历史分析模型

更新：2026-11-20。attitudegimbal.m 是用户提供的历史角度/运动模型脚本，本轮不改原文件。
它与前端 src/filters/sixAxisEskf.ts 的六轴 A0/A4 实现不同：历史脚本使用角度/速度/角加速度及正弦运动模型，不能用它代替机体系原始陀螺和比力输入。

脚本默认读取旧名称XLSX，需要MATLAB和对应输入，执行会生成分析结果；本轮没有运行MATLAB，也不声称它与前端数值等价。真实日志不随公共源码新增分发。指令推算位置、拟合模型和模块融合姿态均非独立姿态真值。

当前操作与对比口径见主README及docs/algorithm-six-axis.md；仅更新说明，不改变历史代码或覆盖原始研究资料。
